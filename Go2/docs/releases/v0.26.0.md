# Go2 / DD-M2 v0.26.0 — Integrated Control Baseline

**Release date:** 2026-11-19  
**Source branch:** `go2-control`  
**Robot:** Unitree Go2 Air, firmware 1.1.12  
**Validation evidence:** operator-confirmed physical testing of the base controller and AI controller. Automated regression was not rerun during preparation of this release record.

## Scope

- Integrated `Go2/go2_control/` web application with one WebRTC session for robot commands, camera video and telemetry.
- Base operator control: W/S and Up/Down forward/backward, A/D lateral, Q/E and Left/Right turn; two on-screen joysticks; Space and UI STOP.
- Posture transitions: stand, balance, sit, rise from sitting and lie down; predefined actions and a demonstration sequence.
- AI gesture control via MediaPipe: Thumb_Up, Closed_Fist, Open_Palm, Victory, Pointing_Up, Thumb_Down and ILoveYou mapped to supported robot actions.
- YOLO11n object recognition and person following, with manual override.
- Implemented safety controls: 300 ms deadman, bounded speeds, STOP on release/disconnect, action whitelist and automatic balancing before motion.

## Verification and constraints

The operator reports successful testing of both base and AI control on the physical robot and considers integration complete. This release record does not certify that every gesture, trick, follow behavior or safety scenario was individually revalidated during this documentation update.

The controller README documents a macOS Python 3.12 environment. Its Linux/WSL DDStation setup requires separate reproducibility checks.

For exact operational instructions and known limitations, see [go2_control/README.md](../../go2_control/README.md).
